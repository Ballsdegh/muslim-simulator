# Симулятор мусульманина

Полноценный игровой веб-симулятор одного дня: распорядок, решения, знания,
достижения и прогресс. Уважительная игра о самодисциплине — числовые
показатели являются условной игровой моделью и не отражают духовный
статус человека.

## Стек

- **React 18 + TypeScript** — компонентная архитектура
- **Vite** — сборка и dev-сервер
- **Tailwind CSS** — премиальная тёмно-изумрудная тема, glassmorphism
- **Собственные inline-SVG иконки** (60+), единый визуальный язык
- **SVG-исламская геометрия** — восьмиконечные звёзды, орнаменты, арки
- **localStorage** — весь прогресс сохраняется между сессиями

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production-сборка в dist/
```

## Что внутри

| Раздел | Описание |
| --- | --- |
| Splash | Эмблема, заголовок «Один день. Много решений.», плавное исчезновение |
| Онбординг | 3 обучающих экрана + имя и аватар (8 медальонов) |
| Главная | Приветствие, дата (включая Хиджру), ближайшая молитва с countdown, цели дня, характеристики, быстрые действия |
| День | Таймлайн дня (5 молитв, приёмы пищи, учёба, сон + случайные события), решения 2–4 варианта, последствия по нескольким параметрам |
| Знания | 8 категорий, 16 уроков с фактами и мини-тестами, XP за прохождение |
| Достижения | 16 достижений с уникальными SVG-иконками, glassmorphism для закрытых |
| Профиль | Уровень с progress ring, статистика, история дней, настройки, сброс |
| Анимации | Level-up, открытие достижения, splash нового дня, итоги дня, тосты |

## Времена молитв

Демо-режим использует условные времена (04:45, 12:30, 15:45, 18:30, 21:30).
Для подключения реальных данных реализуйте провайдер в
`src/data/prayerTimes.ts` (например, через api.aladhan.com) — расписание
дня и countdown подстроятся автоматически.

## Игровая модель

- Иман, Намаз, Знания, Благие дела, Здоровье, Энергия, Настроение,
  Репутация (0–100), Деньги, игровое время, XP/уровни, серия дисциплины.
- Энергия ограничивает доступные варианты, деньги — траты и садака,
  серия даёт множитель XP (до ×1.5), настроение подсказывает отдых.
- Серия сохраняется, если в дне 4+ молитвы или 2+ цели.

Проект не претендует на фетву: там, где школы фикха расходятся, формулировки
нейтральные. Для религиозной практики опирайтесь на знания и советы
компетентных людей.
